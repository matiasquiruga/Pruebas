# Conocimientos Científicos

  

## 1. Fisiología del ejercicio y adaptación muscular
**Tipo:** Científico

  

### Obtención

`Se obtendría mediante investigaciones académicas, libros especializados en ciencias del deporte, estudios sobre entrenamiento funcional, entrevistas con entrenadores certificados y contenido educativo audiovisual como videos explicativos sobre fisiología del ejercicio y adaptación muscular.`

[Fisiología del ejercicio](https://www.youtube.com/watch?v=lTjJAIn6F4A)

[Sistemas energeticos en el deporte](https://www.youtube.com/watch?v=5GJv1ZKKCcQ)

### Etapas del proceso

> Definición:
En esta etapa, el conocimiento sobre fisiología del ejercicio permite establecer cómo funcionarán las rutinas de entrenamiento dentro de FitConnect. Ayuda a definir objetivos realistas, niveles de dificultad y tipos de ejercicios adecuados según la condición física de los usuarios.

> Desarrollo:
Durante el desarrollo, este conocimiento se utiliza para diseñar rutinas progresivas y seguras. También permite implementar ejercicios adaptados para principiantes e intermedios, incorporando descansos, intensidad y progresión muscular de manera correcta.

> Prueba:
En la etapa de prueba, se evalúa si las rutinas generan una experiencia segura y efectiva para los usuarios. Se verifican posibles errores en la intensidad de los ejercicios, riesgos de lesión o dificultades excesivas, realizando ajustes según los resultados obtenidos.

  

### Beneficio

`Permite que FitConnect ofrezca rutinas personalizadas según el nivel físico de cada usuario. También ayuda a crear progresiones y regresiones correctas para evitar lesiones y mejorar la experiencia de entrenamiento dentro de FitConnect.`

## 2. Psicología de la motivación y hábitos saludables

  

### Obtención

`A través de estudios de psicología conductual, papers sobre adherencia al ejercicio, análisis de gamificación y encuestas realizadas a usuarios activos.`

  

### Etapas del proceso

> Definición:
Permite definir cómo FitConnect incentivará la constancia de los usuarios. En esta etapa se analizan mecanismos de motivación, recompensas y objetivos que ayuden a mantener el interés en el entrenamiento.

> Desarrollo:
Durante el desarrollo, este conocimiento ayuda a implementar funciones como sistemas de logros, seguimiento de progreso, recordatorios y desafíos semanales para mejorar la experiencia del usuario y fomentar hábitos saludables.

> Producción:
Una vez lanzada la plataforma, se analizan las reacciones y comportamientos de los usuarios para comprobar si las herramientas de motivación realmente aumentan la participación y la continuidad en el uso de la aplicación.

  

### Beneficio

`Ayuda a aumentar la retención de usuarios mediante sistemas de logros, competencias amistosas y seguimiento de progreso. También permite crear una experiencia más motivadora para que las personas mantengan la constancia en sus entrenamientos.`

# Conocimientos Técnicos

  

## 1. Desarrollo móvil multiplataforma optimizado

  

### Obtención

`Mediante capacitación en frameworks como Flutter o React Native, documentación oficial, cursos de optimización móvil y experiencia práctica en desarrollo de apps livianas.`

  

### Etapas del proceso

> Desarrollo:
En esta etapa se programa la aplicación utilizando herramientas multiplataforma como Flutter o React Native. El objetivo es crear una app rápida, estable y compatible con diferentes dispositivos móviles.

> Prueba:
Se realizan pruebas de rendimiento, velocidad de carga y compatibilidad en distintos teléfonos para verificar que la aplicación funcione correctamente y cumpla con los requisitos establecidos, como iniciar en menos de 3 segundos.

> Producción:
Durante la producción, el conocimiento técnico permite publicar la aplicación de forma estable y optimizada, asegurando una buena experiencia de uso y un consumo reducido de recursos en dispositivos de gama media o baja.

  

### Beneficio

`Permite crear una aplicación rápida, con bajo consumo de recursos y compatible con dispositivos de gama media-baja, cumpliendo el requisito de iniciar en menos de 3 segundos y ocupar menos de 200 MB.`

## 2. Gestión de bases de datos y análisis de métricas

  

### Obtención

`A través del estudio de bases de datos SQL/NoSQL, herramientas de análisis de datos, sistemas cloud y prácticas de backend escalable.`

  

### Etapas del proceso

> Desarrollo:
Permite diseñar la estructura de la base de datos que almacenará información de usuarios, rutinas, estadísticas, progreso físico y registros de entrenamiento de forma organizada y segura.

> Producción:
Una vez implementada la plataforma, este conocimiento permite administrar correctamente la información en tiempo real, garantizando rapidez de acceso y estabilidad en el funcionamiento de la aplicación.

> Mantenimiento:
Durante el mantenimiento, se realizan actualizaciones, respaldos y optimizaciones de la base de datos para evitar pérdida de información y mejorar el rendimiento del sistema a medida que aumenta la cantidad de usuarios.

  

### Beneficio

`Hace posible almacenar el progreso de los usuarios, estadísticas de entrenamiento, fotos y registros de actividad de manera eficiente. Además, permite generar gráficos de rendimiento y adaptar rutinas según los resultados obtenidos.`
